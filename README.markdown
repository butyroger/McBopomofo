# OpenVanilla McBopomofo 小麥注音輸入法

> **這是 [openvanilla/McBopomofo](https://github.com/openvanilla/McBopomofo) 的非官方分支（`smart-learning`），加強選字學習與中英混打，並加入常用句、文字範本、分類符號表、管理詞彙等功能。** 本分支功能的問題請到[本專案 Issues](https://github.com/butyroger/McBopomofo/issues) 回報，官方版本的問題請到原專案。

**下載**：到 [Releases](https://github.com/butyroger/McBopomofo/releases/latest) 下載 DMG，打開後雙擊「安裝小麥注音（智慧學習版）」。本版未經 Apple 公證，第一次打開若被擋，到「系統設定 → 隱私權與安全性」按「強制打開」即可。支援 macOS 12 以上（官方版需 macOS 13）。

**使用說明**：以下內容與[線上使用說明](https://butyroger.github.io/McBopomofo/)、輸入法選單的「使用說明」相同。各版本的變更見 [CHANGELOG.md](CHANGELOG.md)。

## 使用說明

### 基本操作

- 打注音、按聲調（一聲按 <kbd>空白</kbd>）就會組字，打完一句按 <kbd>Enter</kbd> 送出。
- 選字：游標停在要改的字上，按 <kbd>空白</kbd> 或 <kbd>↓</kbd> 開啟候選字，按選字鍵選字。
- 輸入法選單最上方可以直接切換「注音－標準鍵盤」與「注音－許氏鍵盤」。
- 許氏鍵盤的數字鍵不是注音，打中文時直接按數字，數字會跟中文一起留在組字區。
- <kbd>Caps Lock</kbd> 打開時打出的是小寫英文，關掉回到注音。

### 智慧中英切換

不用按 <kbd>Shift</kbd> 或 <kbd>Caps Lock</kbd> 也能中英數混打：打的鍵組不成注音時，會自動變成英文。

範例：

- 你用過這個 app? → 你用過這個 app?
- ChatGPT 很好用 → ChatGPT 很好用
- 2026 年 → 2026年
- ok? → ok?

#### 什麼時候變成英文

- 同一個注音位置又按了一次，例如 `app`（ㄇㄣ 之後又按 ㄣ）。
- 組出來的注音不是字，例如 `you` 加空白（ㄗㄧㄟ 不是字）。
- 按大寫字母，直接開始英文，例如 `ChatGPT`。
- 注音還沒打完就接數字或符號，例如 `ok?`。

#### 回到中文

- 按 <kbd>空白</kbd>、任何符號或 <kbd>Backspace</kbd> 就回到中文。
- 只打了數字時，空白只會回到中文、不插入空白，所以 `2026` 空白 `年` 會是「2026年」。
- 英文打完也可以不按空白，直接接著打中文：打完一個字的注音和聲調，就會自動轉回中文，例如 `hello` 接 `ㄏㄠˇ` → 「hello 好」、`PDF` 接 `ㄉㄤˇ` → 「PDF 檔」。前面要是英文單字（或 PDF 這類大寫縮寫），而且整串不是英文單字或單字的開頭，才會轉換。
- 英文和中文一起留在組字區，按 <kbd>Enter</kbd> 一起送出。

> 很短的英文可能剛好是合法注音，例如許氏鍵盤的 `a` 加空白會打成「疵」，這時請改用 <kbd>Shift</kbd> 或 <kbd>Caps Lock</kbd>。本功能可在偏好設定關閉。

### 中英混打細節

#### 中英文之間自動加空格

中文後面接英文、英文後面接中文時，自動在中間加一個空格。

範例：

- 你好hello → 你好 hello
- 用iPhone拍 → 用 iPhone 拍

- 數字不加空格，例如「2026年」「3個」。
- 用 <kbd>Backspace</kbd> 把英文刪光時，自動加的空格也一起刪掉。

#### 英文、數字後的標點用半形

緊接在英文字母或數字後面的標點自動打半形，接在中文後面的維持全形。

範例：

- 價格是300. → 價格是300.
- 好, → 好，

> 想在英文、數字後面打全形標點，請按住 <kbd>Control</kbd> 再打標點，例如 <kbd>Control</kbd>+<kbd>,</kbd> 一律是「，」。

#### 英文大小寫修正

英文打完按 <kbd>空白</kbd> 時，像 iPhone、OpenAI 這類中間有大寫的字，即使打成小寫也會自動改正。

範例：

- iphone <kbd>空白</kbd> → iPhone
- openai <kbd>空白</kbd> → OpenAI

- 想保留小寫就按 <kbd>Enter</kbd> 送出，不會修正。
- 除了內建的常見字（iPhone、macOS、GitHub、YouTube……），你用大寫打過兩次以上的字（例如 ButyPOS）也會自動修正。
- 只有字首大寫（Apple）或全大寫（NASA）的字不會修正。

> 以上三項都可以在偏好設定的「中英混打」個別關閉。

### 英文聯想

打英文時（或注音還沒打完時）按 <kbd>Tab</kbd>，列出英文單字補完，按選字鍵選。

範例：

- ass <kbd>Tab</kbd> → ass、assuming、assume、assistant、associate…
- hel <kbd>Tab</kbd> → hel、hello、help、helpful…

- 清單第一個是原本打的字，選它等於不改。
- 打過兩次以上的英文字會排在最前面，例如 ChatGPT。
- 跳著打也找得到打過的字，例如 `aocd` 找到 associated。

### 數字與算式

#### 數字快打

按 <kbd>`</kbd> 後輸入數字，列出各種格式，按選字鍵或 <kbd>Enter</kbd> 送出。

範例：

- ` 2023.09.07 → 2023年9月7日（星期四）、二〇二三年九月七日、中華民國112年9月7日、2023/09/07…
- ` 112.9.7 → 民國年也可以，同上
- ` 12:30 → 12時30分、下午十二點三十分、下午12點30分、12:30 PM…
- ` 6548 → 6,548、陸仟伍佰肆拾捌元整、六千五百四十八、6,548元…
- ` 10*15/6 → 25、10*15/6=25、10×15÷6=25、貳拾伍元整…

#### 中文模式直接算

在組字區打算式再按 <kbd>=</kbd>，答案會自動接在後面。全形、半形運算子都可以，數字中間的「。」當小數點。

範例：

- (2+3)*3= → （2＋3）＊3＝15
- 3.5*2= → 3。5＊2＝7

### 常用句

同一句送出三次，就會記住這句。之後在句首或標點後打出開頭兩個字以上，游標旁會提示後半句，按 <kbd>Tab</kbd> 整句接上。

範例：

- 謝謝 <kbd>Tab</kbd> → 謝謝您的耐心等候

- 句子要 6 到 40 個字（英文單字算一個字），不能有標點；有標點時會分成幾句分別記。
- 約三個月沒用到會自動忘掉，用得越多次留得越久。
- 記住的句子存在詞庫的 `learning/sentences/`，多台 Mac 共用。
- 可以在「管理詞彙」的常用句分頁查看、刪除，或直接加入句子（立即生效、不會被遺忘）。偏好設定「中英混打」可關閉。

### 候選字調整

在候選字視窗反白某個字詞時：

- <kbd>+</kbd> 或 <kbd>=</kbd>：提高排序，以後優先出現。
- <kbd>-</kbd> 或 <kbd>_</kbd>：排除，以後不再出現。單字也可以，例如排除「你」，打 ㄋㄧˇ 就會先出現「妳」。
- <kbd>?</kbd>：用辭典查詢。

> 提高排序和排除都會先跳出確認；調整的結果可以在「管理詞彙」的中文詞彙、排除詞彙分頁改回來。

### 文字範本

- 按 <kbd>`</kbd> 後輸入代碼，例如地址、帳號等常用文字，按選字鍵或 <kbd>Enter</kbd> 送出。
- 範本放在詞庫資料夾的 `text-templates.txt`，一行一筆：代碼、Tab、內容，內容要換行請寫 `\n`。
- 從輸入法選單「編輯文字範本」開啟編輯。

### 符號表與 emoji

- 按兩次 <kbd>`</kbd>（或在範本中再按一次 <kbd>`</kbd>）開啟分類符號表。
- 打完標點按 <kbd>空白</kbd> 或 <kbd>↓</kbd>，也會開啟符號表，反白停在剛打的標點。
- 兩鍵選符號：第一鍵選列（左側標示），第二鍵選格；按 <kbd>Backspace</kbd> 回到選列。
- 內建表情、手勢、愛心、動植物、食物、生活、天氣、符號等 emoji 分類。
- 符號表放在 `symbol-table.txt`，一行一類：分類名稱、Tab、以空白分隔的符號；從選單「編輯符號表」開啟。

### 自動學習

- **選字記憶**：選過的字會記住前後文，下次同樣的句子優先出現。
- **暫存詞**：兩個字以上的詞手動選過 1 次，就收進暫存詞，不分前後文都優先出現；30 天沒再用到會自動清除。
- **個人詞庫**：暫存詞之後再打出來送出一次，就寫進個人詞庫（`data.txt`），永久生效。
- **拆詞學習**：內建詞被拆開改字，例如「許是」改成「許氏」，同樣選兩次後會把新詞記下來。
- 學習資料存在詞庫資料夾的 `learning/`，詞庫放在 iCloud 雲碟時，多台 Mac 共用並合併。
- 不想要的詞可以從選單「編輯要排除的詞彙」排除，排除後不會再被自動加回來。

### 管理詞彙

從輸入法選單「管理詞彙…」開啟，不用再直接編輯文字檔。分頁：

- **中文詞彙**：自訂詞優先出現在候選字。輸入詞會自動帶出注音，破音字可以自己改。
- **排除詞彙**：永遠不會出現在候選字的詞。
- **英文詞彙**：英文聯想（Tab）優先列出的字；打過兩次以上的字會自動列在這裡。
- **常用句**：已記住和還在累積次數的句子。
- **暫存詞**：選過一次、還在 30 天期限內的詞，可以刪除或直接加入中文詞彙。
- **文字範本**：按 ` 後輸入代碼插入的內容。

> 在一台 Mac 刪除的英文字、常用句、暫存詞，其他 Mac 也會一起刪除。

### 浮動組字窗

有些 App 會在組字途中自己改動內容，造成漏字或補字重複（常見於網頁裡的編輯器）。遇到這種 App，在輸入法選單勾選「此 App 使用浮動組字窗」：組字中的字改顯示在游標上方的小視窗，按 <kbd>Enter</kbd>、標點等送出時才交給 App。

> 設定是以 App 為單位，例如在 Chrome 勾選後，整個 Chrome 都會使用。再點一次取消。

### 中英提示與模式圖示

- **中英切換提醒**：按 <kbd>Caps Lock</kbd>，或在小麥與其他輸入法之間切換時，螢幕右上角會短暫顯示「ABC」或「中文」。
- **模式狀態顯示**：使用小麥時，選單列顯示「中／英」（Caps Lock 或智慧切換的英文模式時為「英」），也可以另外顯示「全／半」形標點，點一下切換。

### 輸入法變灰（安全輸入）

macOS 有防側錄的「安全輸入」，某個程式開啟後，所有第三方輸入法（包括小麥）都會變灰、無法切換，只剩系統內建的輸入法能用。程式沒有正常解除時，就會一直卡住。

安全輸入持續開啟超過一分半鐘時，小麥會跳出提醒，說明是哪個程式開啟的，以及該怎麼處理。常見原因：

- 密碼管理程式（例如 1Password）。
- 瀏覽器裡沒關的登入頁、密碼欄位。
- 終端機開啟了「安全鍵盤輸入」。

處理方式：依序試試關閉等待輸入密碼的頁面、完全結束該程式、鎖定螢幕再解鎖，最後是登出再登入。

> macOS 回報的程式名稱不一定準確，有時會回報成目前在前景的程式。提醒視窗按「不再提醒」，或在偏好設定關閉「安全輸入提醒」，就不會再跳出。

### 偏好設定

從輸入法選單「小麥注音偏好設定」開啟。本版新增的項目：

- **面板主題**：候選字面板與符號表跟隨系統、淺色或深色。
- **中英切換提醒**：開啟／關閉。
- **智慧中英切換**：不按 Shift、Caps Lock 也能打英文。
- **模式狀態顯示**：中／英模式圖示（預設開）、全／半形模式圖示（預設關）。
- **中英混打**：中英文之間自動加空格、英文數字後的標點用半形、修正英文大小寫（預設都開）。
- **安全輸入提醒**：輸入法被停用時告訴你是哪個程式造成的（預設開）。

### 詞庫檔案

詞庫資料夾可在偏好設定指定，例如 iCloud 雲碟的 `McBopomofo` 資料夾。

- `data.txt`：個人詞庫，一行一筆「詞 注音」，注音之間以 `-` 連接。
- `exclude-phrases.txt`：要排除的詞。
- `text-templates.txt`：文字範本。
- `symbol-table.txt`：符號表。
- `learning/`：選字記憶、`temporary/` 暫存詞、`english/` 打過的英文字，每台 Mac 各寫自己的檔案。

### 快速鍵一覽

- <kbd>`</kbd>：文字範本、數字快打；再按一次開啟符號表。
- <kbd>Tab</kbd>（英文時）：英文聯想。
- <kbd>Tab</kbd>（有常用句提示時）：接上後半句。
- <kbd>+</kbd> <kbd>-</kbd> <kbd>?</kbd>（候選字視窗）：提高排序、排除、查辭典。
- <kbd>=</kbd>（算式後）：自動算出答案。
- <kbd>Caps Lock</kbd>：切換英文小寫。
- <kbd>Shift</kbd> + 字母：直接打英文。
- <kbd>Ctrl</kbd> <kbd>⌘</kbd> <kbd>G</kbd>：輸出簡體中文。
- <kbd>Ctrl</kbd> <kbd>⌘</kbd> <kbd>H</kbd>：切換半形標點。
- <kbd>Esc</kbd>：清除組字區或關閉候選字。

## 技術細節

### 選字學習的儲存方式

原版小麥注音的選字記憶（User Override Model）只存在記憶體、半衰期 1.5 小時、最多 500 筆，重開機或隔天就忘了。本分支的改動：

- **寫入檔案，多台 Mac 共用**：每次選字後約 2 秒內存進詞庫資料夾的 `learning/`。每台電腦只寫自己的檔案（`<裝置代號>-<電腦名稱>.txt`），讀取時合併所有電腦的記錄，不會互相覆蓋或產生同步衝突檔。iCloud 把檔案移出本機（只留 `.icloud` 占位檔）時，會先觸發下載，載入完成前不會覆寫雲端的檔案。
- **記得更久**：半衰期改為 30 天，每台容量 5000 筆。
- **以最後一次選擇為準**：原版依「選過幾次」決定建議哪個字，本分支改為最後選的為準，選錯了重選一次即可更正。
- **其他學習資料**也在 `learning/` 下，同樣每台一個檔案、讀取時合併：`temporary/`（暫存詞）、`english/`（打過的英文字）、`sentences/`（常用句）；`removed.txt` 記錄在「管理詞彙」刪除的項目，讓其他電腦也跟著刪除。
- 想清除學習記錄，刪掉 `learning/` 資料夾裡的檔案即可，或在「管理詞彙」逐筆刪除。

### 其他與原版的差異

- 只保留「小麥注音」一種輸入模式，拿掉「簡單注音」。
- 「檢查更新」指向本分支的 Releases，不會被官方版提示覆蓋。
- **Caps Lock 切換英文會卡、第一個字變大寫**：這是 macOS「使用大寫鎖定鍵切換『ABC』輸入法」造成的，系統要先判斷輕按（切換輸入法）還是長按（大寫鎖定），所以會延遲。建議到「系統設定 → 鍵盤 → 輸入方式」關掉該選項。本分支不向系統宣告「支援 Caps Lock 切換語言」，Caps Lock 一律是一般的大寫鎖定，開啟時小麥直接輸出小寫英文。


## 系統需求

小麥注音輸入法可以在 macOS 13 以上版本運作。如果您要自行編譯小麥注音輸入法，或參與開發，您需要：

- macOS 26 或更高版本
- Xcode 26 或更高版本
- Python 3.9 (使用 Xcode 安裝後內附的就可以，也可使用 homebrew 等方式安裝)

## 開發流程

用 Xcode 開啟 `McBopomofo.xcodeproj`，選 "McBopomofo Installer" target，build 完之後直接執行該安裝程式，就可以安裝小麥注音。

第一次安裝完，日後程式碼或詞庫有任何修改，只要重複上述流程，再次安裝小麥注音即可。

要注意的是 macOS 可能會限制同一次 login session 能 kill 同一個輸入法 process 的次數（安裝程式透過 kill input method process 來讓新版的輸入法生效）。如果安裝若干次後，發現程式修改的結果並沒有出現，或甚至輸入法已無法再選用，只要登出目前帳號再重新登入即可。
